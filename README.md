# ニュースまとめAI（news-digest）

気になるキーワードのニュースを集め、選んだ記事の本文を読んで、自分好みのレポートを作る Claude Code 用プラグインです。

- 情報源は RSS。国内外のニュースサイトと、キーワード検索の2種類を既定で11本使います
- 見出しで候補を絞り、選んだ記事だけ本文を取得して要約します
- 一度読んだ記事は記録され、次回からは前回以降の新着だけが集まります
- 件数、情報源、レポートの構成は、日本語で頼めば変えられます

## インストール

### デスクトップアプリで使う場合

設定 → カスタマイズ → プラグイン → 追加 → マーケットプレイスを追加 → リポジトリから追加 を開き、次を入力します。

```
aiannakaai/news-digest
```

追加したら、一覧の「ニュースまとめAI」をインストールします。

### ターミナルで使う場合

```
/plugin marketplace add aiannakaai/news-digest
/plugin install news-digest@workshop-tools
```

反映するには `/reload-plugins` を実行するか、Claude Code を起動し直します。

### 更新するとき

このリポジトリが更新されたら、次で最新にできます。設定（`preferences.md` と `sources.txt`）は消えません。

```
/plugin marketplace update workshop-tools
```

## 使い方

Claude Code に話しかけます。どのフォルダで起動していても使えます。

```
ニュースをまとめて
```

キーワードを指定することもできます。

```
Claude のニュースをまとめて
```

初回は、読み手のことや件数、情報源について質問があります。答えた内容は設定として保存され、次回から使われます。

レポートは `~/news-reports`（Windows は `C:\Users\<ユーザー名>\news-reports`）に、日付と時刻のファイル名で保存されます。過去のレポートは上書きされません。

## カスタマイズ

日本語で頼むだけです。変更は次回の実行から反映されます。

```
「注目すべき理由」と「自分への影響」の欄を足して
10件にして
TechCrunch も情報源に入れて
さっきの変更を元に戻して
```

設定は `~/news-reports` の `preferences.md`（件数や構成）と `sources.txt`（情報源）に保存されます。プラグインを入れ直しても、これらの設定は残ります。

## 収集スクリプトについて

macOS 用（`collect.sh` / `fetch.sh`）と Windows 用（`collect.ps1` / `fetch.ps1`）を同梱しています。どちらも各 OS に最初から入っている環境で動くため、追加のインストールは要りません。

RSS の取得と整形をスクリプトが行うことで、Claude が読む量を抑えています。本文の取得は、選ばれた記事だけに限っています。

## 制約

- 記事一覧を JavaScript で表示するサイトは、本文を取得できないことがあります。その場合はレポートに「(見出しのみ)」と表示されます
- Google ニュース経由の記事は転送リンクのため、元記事を調べてから本文を取得します。仕様変更で取得できなくなる可能性があります
